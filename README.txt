LITTLE STREET TYCOON

Engine: Godot 4.7.2 stable.

Open project.godot in Godot and press Play.

Controls:
- Mobile: tap the ground to move; use the joystick for direct movement.
- Desktop: WASD/arrow keys or click to move.
- Upgrade button opens the small upgrade menu.

This version is procedural and contains no external asset dependencies. It is intentionally built as a real 3D Godot project rather than a browser page, so the next art pass can replace the procedural meshes with proper low-poly character/building assets without rewriting the gameplay systems.
