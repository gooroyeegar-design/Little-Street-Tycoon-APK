# Little Street Tycoon

Little Street Tycoon is a polished, self-contained 3D/isometric idle business game built for Android.

## Game

Build a small neighborhood into a thriving street. Businesses generate cash automatically while customers walk through the street. Tap a shop to inspect it, then upgrade it when you can afford the next investment.

Included in this build:
- Four distinct businesses with progression.
- Procedural 3D buildings, road, homes, trees and customers.
- Idle cash generation and upgrade economy.
- Street level progression.
- Touch controls designed for phones.
- Clean restrained UI with standard typography.
- No emoji UI and no AI-generated visual assets.
- No runtime network dependency.

## Android APK
