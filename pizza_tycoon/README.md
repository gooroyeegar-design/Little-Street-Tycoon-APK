# Pizza Street Tycoon

A mobile-first 3D restaurant tycoon prototype built with Godot 4.

## First playable build
- Third-person cook character in a 3D restaurant room
- Follow camera, keyboard controls and on-screen mobile joystick
- Starter pizza machine and cook/sell loop
- Buy tables, hire staff and upgrade the oven
- Procedural furniture, lighting, windows and restaurant decor
- Android APK build workflow

## Controls
- Desktop: WASD / arrow keys to move
- Mobile: left joystick to move, on-screen buttons to cook, serve, buy and upgrade

## Build
Open the pizza_tycoon project in Godot 4.3+.
The GitHub Actions workflow builds a debug APK artifact for testing. A Play Store release requires a separately configured release signing key and an Android App Bundle.
